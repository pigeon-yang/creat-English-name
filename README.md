# 英文名生成器 (English Name Generator)

一个基于AI的智能英文名生成工具，采用苹果设计美学标准，为用户提供高质量、个性化的英文名建议。

## 项目概述

### 核心功能
- **智能英文名生成**：基于中文名字智能生成3个英文名建议
- **深度寓意解释**：提供中英文双语寓意解释，包含文化背景和智慧幽默说明
- **苹果设计风格**：采用苹果设计系统，提供优雅的用户体验
- **响应式设计**：完美适配桌面和移动设备

### 技术栈
- **前端**：HTML5 + CSS3 + JavaScript (ES6+)
- **后端**：Node.js + Express
- **AI服务**：DeepSeek API (备用本地生成方案)
- **设计风格**：苹果设计系统 (Apple Design System)

## 遇到的问题及解决方案

### 问题1: 英文名生成错误
**症状**：用户输入中文名后显示"生成英文名出现错误，请稍后重试"

**根本原因分析**：
1. API密钥可能无效或过期
2. AI服务端暂时不可用
3. 网络连接问题
4. 服务器端错误处理机制不完善

**解决方案**：
1. **增强错误诊断**：
   - 添加详细的API密钥检查日志
   - 优化错误处理流程，提供更清晰的错误信息
   - 缩短超时时间从60秒到30秒

2. **完善备用方案**：
   - 创建`generateEnhancedFallbackNames`函数
   - 提供高质量的本地备用英文名生成
   - 支持常见中文姓氏的智能匹配

3. **改进用户体验**：
   - 确保用户始终能获得英文名建议
   - 提供友好的错误提示信息
   - 统一使用备用方案处理各类API异常

### 问题2: 服务器稳定性
**症状**：服务器频繁停止运行

**解决方案**：
- 优化服务器启动脚本
- 添加进程监控和自动重启机制
- 改进错误日志记录

### 问题3: 设计风格不一致
**症状**：界面设计缺乏统一性和专业性

**解决方案**：
- 采用苹果设计系统标准
- 统一色彩、字体、间距规范
- 添加流畅的动画效果
- 优化响应式布局

## 使用方法

### 快速启动
```bash
# 安装依赖
npm install

# 启动服务器
node server.js

# 访问应用
打开 http://localhost:3000
```

### 使用流程
1. 在输入框中输入中文名字
2. 点击"生成英文名"按钮
3. 查看生成的3个英文名建议
4. 可选择重新生成或分享结果

## 故障排除

### 常见问题

**Q: 英文名生成失败怎么办？**
A: 系统会自动切换到高质量的本地备用生成方案，确保用户始终能获得英文名建议。

**Q: 服务器无法启动？**
A: 检查Node.js版本和端口占用情况，确保3000端口可用。

**Q: 界面显示异常？**
A: 清除浏览器缓存，确保所有资源文件正确加载。

### 日志查看
服务器运行日志会显示在终端中，包含详细的错误信息和调试信息。
